## 机房怎么选：4 个测试 IP 和一句实话

| 纽约 | `192.3.81.8` | Cogent、Arelion、GTT |
| 达拉斯 | `198.23.249.100` | TeliaSonera、XO |

中文用户一般在洛杉矶 DC03、西雅图和纽约之间纠结。美西机房到国内的物理距离更短，这是常识层面的判断，具体到你家的宽带，还是得自己测。

测试方法：白天测一次，晚上 20:00–23:00 再测一次，用 ping 看丢包和延迟波动，用 mtr 看回程走哪个运营商。两个时段差异很大，只看白天的结果容易选错。

**一句实话**：RackNerd 官网没有宣传任何机房接入 CN2 GIA、9929 或 CMI 这类回国优化线路。KVM VPS 页面标题里有 “Asia Optimized Network” 字样，正文只提到用 Noction IRP 做路由优化，没有说明具体走哪条回国线路。所以按普通国际线路看待它，别期待晚高峰有优化线路的表现。本文不给延迟数字，因为没有长期测速数据，给了也是编的。

如果你的访客主要在中国大陆，并且很在意晚高峰的稳定性，先测测试 IP。测出来不能接受，就得考虑那些明确主打回国优化线路的商家，价格通常高出一截。这是取舍，不是谁好谁坏。

## 下单到开机：几步别省

1. **选套餐和周期**。年付或两年付，两年付不加价也不打折。
2. **选系统**。下单页标注 Debian 11/12 建议至少 2GB 内存，1GB 套餐别选这两个版本；Ubuntu 22.04 的最低要求是 1GB。拿不准就用 Ubuntu 24.04。
3. **选机房**。按上面测试 IP 的结果选，别默认第一个。
4. **填真实资料**。姓名、地址、常用邮箱都要真实，账单、续费提醒、开机信息都发到这个邮箱。
5. **付款**。结账页支持 PayPal、信用卡、Stripe 支付宝、银联卡、USDT/USDC 稳定币、Boleto 和电汇。国内用户用支付宝最省事，没有微信支付。
6. **开机**。官方说付款后立即开通，几分钟内收到含 IP 和 root 密码的邮件，ctrl 面板里也能查到。

拿到机器后有四件事建议当天做完：改掉默认 root 密码、改用密钥登录并关掉密码登录、在 ctrl 的网络防火墙里只放行需要的端口、配一个异地备份。1GB 那档如果跑 WordPress，加 1–2GB swap，不然数据库和 PHP 抢内存很容易把机器拖死。

需要 IPv6 的话，洛杉矶和法国机房可以开工单免费申请，最多 100 个，其他机房以客服答复为准。
